An API token is a token id and its secret.

Create the token

  1. Open the API settings page in Monte Carlo and click Add.
  2. Choose the type of key, personal or account-level, and when it expires. An account-level key needs a role that allows it; Account Owners have one.
  3. Copy the key id and the secret. The secret is shown only once.

API Authentication in the Monte Carlo docs has the details.

Configure interactively

montecarlo configure

Choose 2, API token, then enter the token id and the secret. The secret is read hidden. configure checks the credentials with Monte Carlo, then writes them to the default profile, or to the one --profile names. montecarlo configure lists its options.

In a script or CI

configure needs a terminal. Write the profile with profile set instead, reading the secret from a file:

montecarlo profile set default --api-id <id> --api-token @<path>

Or, on a terminal, have it ask for the secret with echo off:

montecarlo profile set default --api-id <id> --api-token-prompt

profile set checks the credentials before writing them, as configure does; --no-validate skips the check. See montecarlo profile set.

Or leave the profile out and set these environment variables, which every command reads:

MCD_DEFAULT_API_ID=<id>
MCD_DEFAULT_API_TOKEN=<secret>

Check

montecarlo whoami

It shows the user and account the credentials belong to.
