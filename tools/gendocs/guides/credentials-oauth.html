An OAuth client is a client id, its secret, and the Monte Carlo instance it belongs to, such as us1.

Create the client

  1. Open the API settings page in Monte Carlo and click Add.
  2. Choose an OAuth client. A personal client acts as you; a service client belongs to the account and has its own authorization groups.
  3. Copy the client id and the client secret. The secret is shown only once.

The instance is the Monte Carlo deployment your account runs on, such as us1 or eu1; the scope the dialog shows names it. API Authentication in the Monte Carlo docs has the details, including the permission each type of client needs.

Configure interactively

montecarlo configure

Choose 1, OAuth client, then enter the client id, the secret and the instance. The secret is read hidden. configure checks the credentials with Monte Carlo, then writes them to the default profile, or to the one --profile names. montecarlo configure lists its options.

In a script or CI

configure needs a terminal. Write the profile with profile set instead, reading the secret from a file:

montecarlo profile set default --client-id <id> --client-secret @<path> --instance us1

Or, on a terminal, have it ask for the secret with echo off:

montecarlo profile set default --client-id <id> --client-secret-prompt --instance us1

profile set checks the credentials before writing them, as configure does; --no-validate skips the check. See montecarlo profile set.

Or leave the profile out and set these environment variables, which every command reads:

MCD_DEFAULT_OAUTH_CLIENT_ID=<id>
MCD_DEFAULT_OAUTH_CLIENT_SECRET=<secret>
MCD_DEFAULT_INSTANCE_ID=us1

Check

montecarlo whoami

It shows the user and account the credentials belong to.
